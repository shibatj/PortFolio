# Phanuwat Arsanok — Portfolio

Personal portfolio site: https://phanuwat-arsanok.vercel.app

- **Stack:** Vite, React, GSAP + ScrollTrigger, three.js, and a hand-written WebGL shader background
- **Features:** a TH/EN language toggle, a light/dark theme, a physics-based lanyard badge (Verlet rope with an elastic strap), and a scroll-driven 3D work orbit with custom panel, core and particle shaders

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

All content (profile, projects, awards, timeline) lives in `src/data.js`. UI strings are in `src/i18n.js`.
